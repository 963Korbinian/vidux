# Fonts in this folder

None of these typefaces are ours. All three families are published under the
**SIL Open Font License, Version 1.1**, which permits redistribution with the
font files — which is why this notice travels with them.

|---|---|

| **JetBrains Mono** | © JetBrains s.r.o. — https://github.com/JetBrains/JetBrainsMono |
| **Noto Sans Sinhala**, **Noto Sans Tamil** | © The Noto Project Authors — https://github.com/notofonts |

Full licence text: https://openfontlicense.org/open-font-license-official-text/

The files here are the `woff2` web subsets as served by Google Fonts
(latin and latin-ext for Inter and JetBrains Mono; the Sinhala and Tamil
ranges for Noto). They are carried locally so the app keeps working when
there is no network — fetching them at runtime would break exactly the
promise this app makes.
